# Chess piece artwork

The SVG files in this folder are the Cburnett chess pieces used by Lichess.

- Author: Cburnett
- Source: https://github.com/lichess-org/lila/tree/master/public/piece/cburnett
- Original set: https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces
- License: Creative Commons Attribution-ShareAlike 3.0 Unported (CC BY-SA 3.0)
- License text: https://creativecommons.org/licenses/by-sa/3.0/

The files are used unchanged; the application only changes their display size with CSS.
