# Chess.amy

Локальный шахматный тренажёр с анализом партий, турнирами и уникальным аметистовым ходом.

Chess.amy — офлайн-приложение на Flask и python-chess: партии с ботами Stockfish, 15 турниров, разбор каждой партии с 13 ярлыками, тренер с озвучкой, кубки и титулы. Работает на `localhost`, внешние API и интернет не нужны.

> Это отдельная cheat-версия Chess.amy. Она запускается на порту 5001 и не требует отдельного чит-скрипта: подсказки встроены в страницу партии.

## Фишки

- 15 турниров до Чемпионата мира — от 800 до 3400+ Эло.
- 13 ярлыков ходов: `brilliant !!`, `amethyst !!!`, `ideal ∞`, `great !`, `best`, `excellent`, `good`, `book`, `inaccuracy ?!`, `mistake ?`, `blunder ??`, `miss`, `forced`.
- Быстрая модель «1 Эло»: играет почти случайно, но с шансом 3.4% видит угрозу. Доступна для контролей `1+0`, `2+1`, `3+0`, `3+2`, `5+0`.
- 15 уровней Stockfish для контролей `5+3`, `10+0`, `10+5`, `15+10`, `30+0`.
- Онлайн с ботами: случайные имена и рейтинг в диапазоне −200…+100 от вашего Эло.
- Бот думает минимум 3 секунды за ход; фигуры двигаются по доске плавно.
- 10 тренеров с разными характерами, динамическим текстом и озвучкой. Тренер выбирается после регистрации один раз и не меняется.
- Кубки и титулы за турниры. Кубки видны отдельным списком в профиле и счётчиком в топбаре.
- Аккаунты с хэшированием паролей и режимом «Запомнить навсегда».
- Анализ только после партии: replay с иконками ярлыков, стрелками лучшего хода и точностью в процентах.
- Эло от 500 до 4000, титул «Легенда» на 4000. Эло меняется только в турнирах и режиме «Онлайн с ботами».
- SQLite: база создаётся автоматически при первом запуске.
- Все данные и партии остаются на вашем компьютере.

## Чит

Cheat-режим встроен в игровую страницу. Во время партии в панели справа есть кнопка «Показать лучший ход» и авто-подсказка:

- стрелка на доске показывает лучший ход;
- рядом с ходом видна оценка, ярлык и глубина поиска;
- подсказка делает два прохода: глубокий поиск лучшего хода и отдельный перебор 12 кандидатов, чтобы найти аметистовый, блестящий или идеальный ход, если он не хуже лучшего по оценке;
- отдельный чит-скрипт запускать не нужно: это обычное приложение из папки `ChessAmyCH`.

Папка `ChessAmyCH` лежит рядом с основной сборкой: `ChessAmy1/ChessAmyCH`. Основное приложение (`ChessAmy/app.py`) поднимает её автоматически на порту 5001. Отдельный запуск — `python app.py` из этой папки, адрес http://127.0.0.1:5001.

## Установка

### Windows, пошагово

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/). При установке отметьте «Add Python to PATH».
2. Установите зависимости:

```bat
pip install flask python-chess werkzeug
```

Или через файл зависимостей:

```bat
pip install -r requirements.txt
```

3. Скачайте Stockfish с [stockfishchess.org/download](https://stockfishchess.org/download/), выберите сборку для Windows x86-64, распакуйте архив, переименуйте exe в `stockfish.exe` и положите в папку `stockfish/`.

   В локальном zip-архиве ChessAmy.zip Stockfish 19 уже лежит в `stockfish/stockfish.exe`. В GitHub-репозиторий exe не попадает из-за размера и правила в `.gitignore`, поэтому для клона его нужно скачать отдельно.

4. Запустите приложение:

```bat
python app.py
```

5. Откройте в браузере:

```text
http://127.0.0.1:5001
```

### Виртуальное окружение (рекомендуется)

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

### Другой порт

```bat
set PORT=8080
python app.py
```

В PowerShell: `$env:PORT=8080; python app.py`.

### Если Stockfish не найден

Приложение всё равно запустится на встроенном учебном движке: боты будут играть слабее, а разбор — менее точным. В интерфейсе появится предупреждение. Для полноценной игры и анализа положите `stockfish.exe` в папку `stockfish/` и перезапустите `app.py`.

## Данные и обновления

Аккаунты, партии и настройки хранятся вне папки приложения — обновление файлов их не сбрасывает:

- база: `%LOCALAPPDATA%\ChessAmyCH\database.db`;
- секрет сессий: `%LOCALAPPDATA%\ChessAmyCH\.secret_key`;
- автобэкапы: `%LOCALAPPDATA%\ChessAmyCH\backups\database-*.db` (хранятся последние 20).

При первом запуске `database.db` из старой папки автоматически копируется в новое место. Пароли хранятся только в виде хешей: посмотреть исходный пароль нельзя, но вход и статистика сохраняются. Не удаляйте `%LOCALAPPDATA%\ChessAmyCH`.

## Как играть

- Зарегистрируйтесь: ник 3–20 символов, пароль 4–20 символов, обязательно буква и цифра. Разрешены `_`, `!`, `?`.
- Сразу после регистрации выберите тренера. Это решение сохраняется навсегда.
- «Запомнить навсегда» — при следующем заходе появится окно «Ты — ник?».
- «Пропустить» — гостевой режим: обычные игры без Эло и турниров.
- «Игры» — партии с ботами, Эло не меняется.
- «Онлайн с ботами» — партии на Эло; соперники случайные, имена и рейтинг в диапазоне −200…+100 от вашего Эло.
- «Турниры» — только с аккаунтом.

## Тренеры

После регистрации открывается страница выбора: 10 тренеров с разными характерами и голосами. Тренер закрепляется за аккаунтом и не меняется.

Текст тренера собирается локально из контекста хода: фигура, клетка, потеря сантипешек, оценка до и после, лучший ход движка, фаза партии, жертва или взятие. Готовых сообщений на каждый ярлык нет — фразы строятся под конкретную ситуацию, а 10 стилей дают разную манеру.

Озвучка работает через `SpeechSynthesis` браузера: кнопка «Озвучить» и режим «Авто» в панели разбора. Набор голосов зависит от установленных в системе русских голосов; тренеры дополнительно различаются высотой и темпом речи. Внешний API не используется.

## Анализ партии

Разбор открывается только после завершения партии. Stockfish считает каждую позицию один раз, результат кэшируется в `database.db`.

Ярлыки:

- `brilliant (!!)` — жертва любой фигуры, после которой движок видит форсированный мат в 2+ хода. Ход лучший или почти лучший: потеря 0–20 cp, оценка после не хуже.
- `amethyst (!!!)` — жертва любой фигуры, после которой у соперника нет защиты от мата в 1 ход. Ход лучший или почти лучший, оценка после не хуже.
- `ideal (∞)` — ход создаёт угрозу мата в 1 ход: если соперник ошибётся, мат следует сразу. Ход не хуже «хорошего»: потеря до 50 cp, оценка после не хуже -0.50. Если это жертва с форсированным матом, приоритет у `amethyst` или `brilliant`.
- `great (!)` — критически важный ход, который держит позицию.
- `best`, `excellent`, `good` — точные ходы по оценке движка.
- `book` — дебютная теория.
- `inaccuracy (?!), mistake (?), blunder (??)` — ухудшение оценки на 50–100, 100–200 и 200+ cp.
- `miss` — упущенная победа: перевес был, но после хода исчез.
- `forced` — единственный законный ход.

`brilliant`, `amethyst` и `ideal` редкие: для них нужен особый мотив — жертва и/или угроза мата в 1 ход. Иконка ярлыка показывается маленькой в правом верхнем углу клетки: `!!` — бирюзовый бриллиантовый кружок, `!!!` — фиолетовый аметистовый, `∞` — золотой идеальный. Если SVG-файла нет, появляется текстовая метка `!!`, `!!!` или `∞`. Точность считается по средней потере сантипешек на ход. В панели тренера видны оценка до/после, потеря cp, кнопка озвучки и режим «Авто».

## Графика

Фигуры — набор Cburnett, который использует Lichess. Автор: Cburnett, лицензия CC BY-SA 3.0. Источник: [lichess-org/lila](https://github.com/lichess-org/lila/tree/master/public/piece/cburnett). Подробности — в `static/pieces/ATTRIBUTION.md`. Приложение меняет только размер отображения фигур через CSS.

## Контроль времени

- `1+0` — на часах 1:00, но таймер не тикает: бесконечное раздумье, партия не заканчивается по времени.
- `2+1`, `3+2`, `5+3`, `10+5`, `15+10` — базовое время плюс инкремент за каждый ход.
- `3+0`, `5+0`, `10+0`, `30+0` — базовое время без инкремента.
- Инкремент начисляется после хода. Просрочка фиксируется на сервере.

## Эло и турниры

- Старт 500, минимум 0, максимум 4000. На 4000 выдаётся титул «Легенда».
- Ожидаемый результат: `E = 1 / (1 + 10^((R_bot - R_user) / 400))`, K-фактор уменьшается с ростом рейтинга.
- Первый турнир открыт сразу, остальные — через случайное время от 10 до 60 дней. Даты сохраняются в базе.
- Победа в партии ведёт в следующий раунд, поражение или ничья отнимают жизнь.
- За победу в турнире выдаются кубок и титул. Кубки и титулы отображаются в профиле; счётчик кубков есть в топбаре.

## Технологии

- Python 3.12, Flask, Werkzeug, python-chess.
- SQLite, HTML5, CSS3, vanilla JavaScript.
- Stockfish 19 (UCI) для ботов и анализа.
- SpeechSynthesis браузера для озвучки тренера.

## Проверка

Проверены регистрация и вход, выбор и неизменность тренера, гостевой режим, партия с ботом, сдача, разбор Stockfish, точность, новые правила `brilliant/amethyst/ideal` (реальная жертва ферзя `Qb8+` с матом в 1, ветка с форсированным матом в 2+ и `Qh5` с угрозой мата в 1 ход), replay назад/вперёд, угловые иконки `!!`/`!!!`/`∞`, озвучка, кубки в профиле и топбаре, все 10 контролей с инкрементами, мат, пат, ничья, сдача и просрочка времени, турнир и разбор партии ботов.

```bat

git remote add origin https://github.com/YOUR_USERNAME/ChessAmy.git
```

Замените `YOUR_USERNAME` на свой логин GitHub (латиницей). Перед `git add .` проверьте `git status`: `database.db`, `.secret_key`, логи и `stockfish/stockfish.exe` должны быть проигнорированы через `.gitignore`.
