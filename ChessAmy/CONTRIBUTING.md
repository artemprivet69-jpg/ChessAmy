# Как внести вклад в Chess.amy

Спасибо за интерес к проекту. Ниже — короткие правила, чтобы изменения было легко проверить и принять.

## Сообщить об ошибке

- Откройте Issue в репозитории.
- Укажите операционную систему, версию Python и Stockfish, шаги воспроизведения, ожидаемое и фактическое поведение.
- Приложите текст ошибки из консоли, если он есть.
- Не прикладывайте `database.db`, `.secret_key`, cookies, пароли и другие личные данные.

## Предложить изменение

1. Сделайте форк репозитория и создайте отдельную ветку.
2. Внесите изменение и опишите в Pull Request, что и зачем сделано.
3. Проверьте, что приложение запускается командой `python app.py`.
4. Проверьте регистрацию, выбор тренера, партию с ботом и разбор после партии.
5. Убедитесь, что в коммит не попали `database.db`, `.secret_key`, логи и `stockfish/stockfish.exe`.

## Стиль проекта

- Интерфейс и документация — на русском языке.
- Не добавляйте эмодзи в код и интерфейс.
- Сохраняйте офлайн-работу: не добавляйте обязательные внешние API и сетевые зависимости.
- Не коммитьте секреты, токены, пароли и персональные данные.
- Для новых ярлыков и тренеров обновляйте README и тестовые сценарии.
